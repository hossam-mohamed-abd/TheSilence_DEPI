# Project Diagrams

## Overview

This directory contains all technical diagrams used throughout the MediSearch project.

These diagrams provide a visual representation of the system architecture, data flow, software components, database structures, and engineering processes. They serve as the primary reference for understanding how different parts of the project interact.

---

# Purpose

This folder is intended to document the project's technical design using industry-standard diagrams.

The diagrams help developers, data engineers, reviewers, and team members understand the system without reading the implementation details.

```text
Recommendation_Engine_Flow.pdf
```

---

# Best Practices

- Keep diagrams up to date.
- Use consistent naming conventions.
- Include version updates when major changes occur.
- Store editable source files whenever possible (Draw.io, PlantUML, Mermaid).
- Export PDF or PNG versions for documentation and presentations.

---

# Notes

This folder stores diagrams only.

Do not store:

- Source code
- Datasets
- Reports
- Presentations
- Documentation unrelated to diagrams

Related documentation can be found in:

```text
docs/
```

while implementation source code is located in:

```text
web_app/
backend/
pipelines/
analytics/
```
