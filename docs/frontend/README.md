# Frontend Documentation

## Purpose

Stores documentation for the user-facing application layer.

## Contents

UI behavior notes, frontend architecture references, user flows, and client-side documentation when available.

## Intended Audience

Frontend developers, UI/UX contributors, QA engineers, and reviewers.

## Related Documentation

See `diagrams/ui_flows/` and `api/` for related user-flow and integration context.

## Maintenance Notes

- Keep existing documentation intact.
- Add new documentation to the most specific folder available.
- Use clear, descriptive filenames that reflect the document purpose.
