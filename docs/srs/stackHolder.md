Main Stakeholders
1️⃣ End Users / Patients

المستخدم الأساسي للنظام.
يبحث عن الأدوية والبدائل والأسعار والتوصيات الطبية.

2️⃣ Pharmacists

يدير الأدوية والأسعار والتوافر داخل الصيدلية.
يساعد المستخدمين ويحدث بيانات الأدوية.

3️⃣ Pharmacy Owners

يديرون الصيدليات والفروع والمبيعات.
يراقبون الأرباح والمخزون والتقارير.

4️⃣ Doctors

يستخدمون النظام لمراجعة الأدوية والبدائل.
يساعدهم في اتخاذ قرارات علاجية أسرع.

5️⃣ Medical Administrators

يشرفون على المحتوى الطبي وجودة البيانات.
يراجعون صحة المعلومات الطبية داخل النظام.

6️⃣ System Administrators

يديرون النظام بالكامل والصلاحيات والمستخدمين.
يراقبون التشغيل والاستقرار والأمان.

7️⃣ Data Analysts

يحللون بيانات الاستخدام والبحث والتوصيات.
يستخرجون تقارير وإحصائيات تساعد تطوير النظام.

8️⃣ AI / ML Team

يبنون ويطورون موديلات الذكاء الاصطناعي.
يحسنون دقة التوصيات والتحليل الطبي.

9️⃣ Customer Support Team

يساعدون المستخدمين في حل المشكلات.
يتابعون الشكاوى والاستفسارات.

Pharmacy & Marketplace Stakeholders
🔟 Pharmacy Branch Managers

يديرون فروع الصيدليات المختلفة.
يتابعون المخزون والأسعار والأداء اليومي.

1️⃣1️⃣ Inventory Managers

مسؤولون عن إدارة المخزون والكميات.
يتابعون النواقص وتحديث التوافر.

1️⃣2️⃣ Suppliers / Drug Suppliers

يوفرون الأدوية للصيدليات والمنصة.
يحدثون الأسعار والكميات المتاحة.

1️⃣3️⃣ Delivery Representatives

يقومون بتوصيل الطلبات للمستخدمين.
يتابعون حالة الطلبات والشحنات.

1️⃣4️⃣ Financial Managers

يتابعون الإيرادات والمدفوعات والفواتير.
يراقبون الأداء المالي للنظام.

1️⃣5️⃣ Sales & Marketing Team

يجذبون المستخدمين والصيدليات للمنصة.
يديرون الحملات التسويقية والعروض.

AI & Analytics Stakeholders
1️⃣6️⃣ Recommendation Engine

المسؤول عن اقتراح الأدوية المشابهة.
يعتمد على تحليل البيانات والتشابهات الطبية.

1️⃣7️⃣ Analytics System

يجمع ويحلل بيانات النظام والاستخدام.
يوفر Insights وإحصائيات للإدارة.

1️⃣8️⃣ Reporting System

ينشئ تقارير تشغيلية وطبية وتحليلية.
يساعد الإدارة في اتخاذ القرارات.

1️⃣9️⃣ Fraud / Abuse Monitoring

يراقب الاستخدامات المشبوهة أو الخاطئة.
يحمي النظام من التلاعب والـ spam.

External Stakeholders
2️⃣0️⃣ Pharmaceutical Companies

توفر بيانات ومنتجات دوائية للنظام.
قد تستخدم المنصة لعرض منتجاتها.

2️⃣1️⃣ Insurance Companies

قد تربط تغطية التأمين بالأدوية.
تتحقق من الأدوية والأسعار والتغطيات.

2️⃣2️⃣ Healthcare Organizations

تستفيد من البيانات والتحليلات الطبية.
قد تستخدم النظام في الخدمات الصحية.

2️⃣3️⃣ Regulatory Authorities

تراقب التزام النظام بالقوانين الطبية.
تراجع سلامة البيانات والتوصيات.

Technical Stakeholders
2️⃣4️⃣ Frontend Developers

يبنون واجهات المستخدم وتجربة الاستخدام.
يربطون الواجهة مع الـ APIs والأنظمة.

2️⃣5️⃣ Backend Developers

يبنون منطق النظام والـ APIs وقواعد البيانات.
يديرون عمليات البحث والتوصية والربط.

2️⃣6️⃣ Database Engineers

يصممون قواعد البيانات والـ Data Warehouse.
يحسنون الأداء والتخزين والاستعلامات.

2️⃣7️⃣ DevOps Engineers

يديرون النشر والسيرفرات والبنية التحتية.
يتابعون الاستقرار والأداء والتشغيل.

2️⃣8️⃣ Security Engineers

يحافظون على أمان النظام والبيانات.
يحاربون الاختراقات والثغرات الأمنية.

2️⃣9️⃣ Cloud Infrastructure Team

يديرون الخدمات السحابية والاستضافة.
يوفرون التوسع والاعتمادية العالية.

3️⃣0️⃣ QA / Testing Team

يختبرون النظام ويكتشفون الأخطاء.
يضمنون جودة واستقرار التطبيق.

Future Stakeholders
3️⃣1️⃣ Hospitals

قد تستخدم النظام داخل العمليات الطبية.

3️⃣2️⃣ Clinics

تستخدمه لإدارة وصفات الأدوية والبحث.

3️⃣3️⃣ Medical Researchers

3️⃣4️⃣ AI Researchers

3️⃣5️⃣ Healthcare Partners

Internal Systems Stakeholders

يدير تسجيل الدخول والصلاحيات.
يحمي حسابات المستخدمين.

3️⃣7️⃣ Notification System

يرسل التنبيهات والإشعارات للمستخدمين.
يبلغ بالتحديثات والعروض والحالات.

3️⃣8️⃣ Payment System

يدير عمليات الدفع والفواتير.
يتابع المعاملات المالية.

3️⃣9️⃣ Recommendation System

ينتج التوصيات الطبية الذكية.
يحلل التشابه والعلاقات بين الأدوية.

4️⃣0️⃣ Search Engine

ينفذ البحث الذكي داخل المنصة.
يدعم الأخطاء الإملائية والعربية.

4️⃣1️⃣ Inventory System

يدير كميات الأدوية والتوافر.
يحدث المخزون لحظيًا.

4️⃣2️⃣ Pricing Engine

يقارن الأسعار بين الصيدليات.

4️⃣3️⃣ Order Management System

يدير الطلبات وحالاتها.

4️⃣4️⃣ Data Warehouse

يخزن البيانات التحليلية والذكاء الاصطناعي.

4️⃣5️⃣ ML Pipeline

يعالج البيانات ويبني موديلات AI.

4️⃣6️⃣ API Gateway

ينظم الاتصال بين الأنظمة والخدمات.

4️⃣7️⃣ Logging & Monitoring System

يسجل العمليات والأخطاء والنشاطات.
يساعد في المراقبة وتحليل المشاكل.

4️⃣8️⃣ Audit System

يتابع كل التغييرات والعمليات الحساسة.
يوفر تتبعًا ومراجعة للأنشطة.

4️⃣9️⃣ Backup & Recovery System

يحفظ نسخًا احتياطية من البيانات.
يساعد على استعادة النظام عند الأعطال.

5️⃣0️⃣ Security & Access Control System

يتحكم في الصلاحيات ومستويات الوصول.
يحمي البيانات والخدمات الحساسة.
